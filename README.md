# نشرة الطقس · الجزائر (PWA)

تطبيق ويب قابل للتثبيت يصنع نشرة طقس الجزائر بالدارجة: بيانات حقيقية من Open-Meteo ← نص ظريف من Gemini ← صوت Gemini TTS ← فيديو MP4 يُسجَّل داخل المتصفح (خريطة متحركة + مذيع «عمي الطقس»). كل شيء يعمل على جهاز المستخدم، بلا خادم.

## النشر على GitHub Pages
1. أنشئ مستودعاً جديداً وارفع **محتويات** هذا المجلد في الجذر (يجب أن يكون `index.html` في الجذر).
2. من Settings ← Pages ← Source: `Deploy from a branch` ← الفرع `main` والمجلد `/ (root)`.
3. افتح الرابط `https://USERNAME.github.io/REPO/` على الهاتف ثم «تثبيت التطبيق» من القائمة أو من زر «تثبيت» داخل التطبيق.

## الاستعمال
1. افتح ⚙️ الإعدادات (أعلى الشاشة) وألصق مفاتيح Gemini (مفتاح في كل سطر): خانة للتحليل وخانة للصوت.
2. اختر نموذج التحليل ونموذج الصوت (الشارات: 🟢 مجاني / 🔴 مدفوع، ⚡ سريع / 🐢 بطيء) واضغط حفظ. جرّب «▶ جرّب الصوت بالدارجة» لتقييم اللهجة.
3. من الرئيسية اختر اليوم (اليوم، غداً، بعد غد، ثم 4 أيام بتواريخها) واضغط «أنشئ كل شيء» أو نفّذ الخطوات واحدة واحدة (١ النص ٢ الصوت ٣ الفيديو).
4. لون زر اليوم يتغير: أبيض (لم تُنشأ) ← أزرق (نص) ← أصفر (صوت) ← أخضر (فيديو جاهز).
5. بعد الفيديو تُولَّد نصوص النشر (خطوة ٤): وصف تيك توك وعنوان ووصف Shorts، وتجدها أسفل الخريطة مع أزرار النسخ.
6. أثناء تسجيل الفيديو أبقِ الشاشة مفتوحة ولا تغادر الصفحة (المدة تساوي طول النشرة).

## البنية
```
index.html            الصفحة الرئيسية
manifest.webmanifest  إعدادات التثبيت
sw.js                 العمل دون اتصال (غيّر VERSION مع كل إصدار)
css/style.css
icons/                أيقونات التطبيق
js/config.js          رقم الإصدار + قوائم النماذج والأصوات
js/app.js             الواجهة وخطوات الإنتاج
js/gemini.js          استدعاء Gemini + تدوير المفاتيح + نموذج احتياطي
js/prompt.js          بناء الطلب وتحليل ردّ النموذج
js/weather.js         Open-Meteo وتلخيص المناطق
js/wilayas.js         الولايات الـ58 والمناطق العشر
js/outline.js         حدود الخريطة المبسّطة
js/mapview.js         رسم الخريطة والمذيع والتعليق على canvas
js/player.js          المشغّل + تسجيل الفيديو (MediaRecorder)
js/mp4fix.js          تحويل MP4 المجزَّأ إلى MP4 عادي (لقبوله في فيسبوك)
js/publish.js         نصوص تيك توك ويوتيوب Shorts
js/audio.js           الصوت: WAV وتحليل المستوى
js/db.js              حفظ النشرات في IndexedDB
js/storage.js         حفظ الإعدادات
js/bulletin.js        مراحل النشرة
js/util.js            التواريخ وأدوات صغيرة
```

## ملاحظات
- يُحوَّل الفيديو بعد التسجيل إلى MP4 عادي (المدة في بداية الملف) ليُقبل عند الرفع على فيسبوك ويوتيوب وتيك توك. إن حُفظ بصيغة WebM (فايرفوكس) فقد لا يقبله فيسبوك؛ استعمل Chrome.
- المفاتيح تُحفظ في `localStorage` على جهازك فقط ولا تُرفع إلى GitHub. الحصة المجانية مرتبطة بمشروع Google لا بالمفتاح، فاستعمل مفاتيح من مشاريع مختلفة.
- النشرات المحفوظة تُحذف تلقائياً عندما يمضي يومها.
- الخريطة مبسّطة لأغراض العرض، وحدودها تقريبية.
- لتحديث التطبيق: ارفع الملفات الجديدة فوق القديمة؛ يتحدّث تلقائياً (أو «التحقق من التحديث» في الإعدادات).
